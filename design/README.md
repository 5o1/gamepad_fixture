# Editable design sources

`source/edit_table_up/` holds the accepted upper-assembly STEP inputs in original assembly coordinates (mm). `source/print/` holds their manufacturing orientations and frozen STL meshes. These are source CAD snapshots, including the owner-edited Fusion slider; they are not claimed to be fully parametric feature-history documents.

The independent build regenerates the16mm acrylic base and its fastener stack, retains the35 upper/source bodies unchanged, and writes the drawings and delivery package. The four original base-bolt inputs provide their accepted mounting positions; the old printed base is not distributed as an active design.
