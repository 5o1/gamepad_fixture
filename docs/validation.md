# Validation scope

Current acrylic delivery: nominal CAD readback, all56 named solids, original upper-body positions,6/50 assembly subsets, exact unchanged production STL files, board hole/counterbore dimensions and fastener intersections.

M5 bolt-body static screening uses ISO898-1 class8.8 data under explicit assumed forces/preloads; it is not a measured operating load, fatigue assessment or joint certification. Details: [bolt calculation](validation/螺丝强度计算说明.md).

No physical print, machined PMMA strength, insert/PMMA cracking, clamp creep or complete manipulation success is certified. Previous upper-assembly nominal spring-envelope contact remains an explicitly accepted design exception; no relief has been applied to the owner-edited slider.

The source geometry came from the reviewed fixture v3.2 work in gamepad_vla. This independent repository does not include workstation control, remote node profiles or private execution logs.
